# @repo/ui

Shared shadcn/ui components and the design tokens for Orbitalis.

```tsx
import { Button } from "@repo/ui/components/button";
```

- Tokens, motion values and global styles: `src/styles/globals.css`
- Components: `src/components/*`
- shadcn config: `components.json`

Add a component from the repo root:

```bash
npx shadcn@latest add dialog -c packages/ui
```

Design rules are in [design.md](../../design.md).
